# Garasi Nugi E-Commerce

Website e-commerce Garasi Nugi untuk penjualan spare part mobil premium.

## Project Structure

- `frontend/` - Frontend application
- `backend/` - Backend API

## Tech Stack

### Frontend
- Next.js
- TypeScript
- Tailwind CSS

### Backend
- NestJS
- Node.js
- Prisma
- PostgreSQL

## Git Workflow

- `main` - Production
- `develop` - Development
- `feature/*` - Pengerjaan fitur
